# Compact Review Scope

Tập trung vào:

1. Brand/product identity, visual hierarchy và merchandising.
2. Navigation, catalog/search, product detail, size/color selection.
3. Cart, quote, voucher/promotion, pickup/delivery, payment và order tracking.
4. Fulfillment, POS, reporting, People & Access và storefront management.
5. Responsive layout, touch targets, tables, dialogs và mobile navigation.
6. Semantics, keyboard/focus, labels, contrast, errors, loading/empty states.
7. VI/EN text length, terminology và hardcoded strings.
8. Shared CSS/components, local state, persistence, API boundary và recovery states.

Mỗi finding phải ghi rõ loại: confirmed defect, likely UX issue, visual/design weakness, implementation risk, optional improvement, hoặc feature request. Thiếu feature không tự động là bug. Không claim WCAG compliance hay backend correctness nếu không có evidence.
