# QLCHGiay
Project Spring Boot quản lý cửa hàng sneaker, giữ giao diện đăng nhập/dashboard của folder dự án và dùng SQL Server database `QuanLyBanHang`.

## Chạy
1. Chạy `QuanLyBanHang.sql` trong SSMS.
2. Kiểm tra `src/main/resources/application.properties`.
3. Chạy `./mvnw spring-boot:run` hoặc `mvnw.cmd spring-boot:run`.
4. Mở http://localhost:8081/login

Tài khoản dữ liệu mẫu: admin / 123456
