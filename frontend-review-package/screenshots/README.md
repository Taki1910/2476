# Screenshot Evidence

These are existing image captures copied from project artifacts. Logs, reports, runtime jars, browser scripts, and machine output from those artifact directories were excluded.

The folder names preserve the capture provenance:

- `product-ui-audit/`: broad route/state/viewport matrix.
- `phase15b/`: selected catalog, search, product, cart, and order flows.
- `phase16/`: pickup and delivery flows.
- `refinement/`: representative refined customer and staff surfaces.

Filenames encode route/state, language where available, and viewport width. See `../04_SCREENSHOT_CHECKLIST.md` for gaps and optional manual captures.
