# Frontend Tests

Tests remain in `frontend/src` because that is where the copied `vitest run` script discovers them. They are not duplicated here.

Included test coverage covers:

- API parsing and error behavior
- session and permission behavior
- cart ownership, quantity limits, and checkout flow
- checkout, quote, pricing, and payment-related UI state
- commerce rendering and product media
- promotions, vouchers, and claimable offers
- storefront homepage and storefront-management behavior
- fit assistant behavior
- English/Vietnamese localization and formatting
